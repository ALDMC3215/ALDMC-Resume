# ALDMC Resume — Personal Portfolio Website
### وبسایت پورتفولیو و رزومه تعاملی علی فرقانی (Ali Forghani)

یک وبسایت تک‌صفحه‌ای شخصی، مدرن و با کیفیت پروداکشن برای **علی فرقانی** — طراح محصول، طراح تجربه و رابط کاربری (UI/UX)، متخصص راهکارهای خلاقانه با هوش مصنوعی و مدرس؛ پیاده‌سازی شده بر اساس هویت بصری رسمی **ALDMC Persimmon V6** و رزومه مستند فارسی.

---

## ویژگی‌های کلیدی پروژه

1. **هویت بصری معتبر خرمالویی (Persimmon V6)**:
   - پالت رنگی رسمی: خرمالویی (`#E76338`)، ذغالی (`#27211D`)، کاغذی (`#F6F0E7`) و هلویی همراه (`#F6B393`).
   - تایپوگرافی دوگانه متغیر: `Vazirmatn` برای متون فارسی و `Manrope` برای اعداد و عبارات لاتین.
   - هندسه برداری رسمی نشان‌ها: لوگوتایپ ALDMC، مونوگرام هندسی A و نشان‌های اختصاصی بدون نیاز به فونت خارجی.
2. **دو حالت روشنایی اختصاصی (Light & Dark Themes)**:
   - حالت روشن (Paper): زمینه کاغذی گرم، متن ذغالی و نشان‌های برجسته خرمالویی.
   - حالت تیره (Charcoal): زمینه ذغالی عمیق، متون نرم کاغذی و درخشش حساب‌شده خرمالویی.
   - سوییچر تم پیشرفته با ذخیره‌سازی وضعیت در `localStorage` و پشتیبانی از تم سیستم‌عامل.
3. **طراحی راست‌چین بومی (Native RTL)**:
   - تنظیم دقیق جهت متن، فاصله‌گذاری، فاصله‌سطر `1.8` برای خوانایی متن فارسی.
   - ایزوله‌سازی صحیح متون انگلیسی و واژگان تخصصی (`dir="ltr"`).
4. **ساختار ماژولار و ادیتوریال**:
   - چیدمان نامتقارن و چشم‌نواز با الهام از استودیوهای پیشرو دیزاین دیجیتال (بدون فرمت‌های تکراری و قالب‌های هوش مصنوعی).
   - ۱۰ بخش کامل: ناوبری چسبان، هیرو ادیتوریال، درباره من، حوزه‌های تخصص، سوابق حرفه‌ای، پروژه‌های منتخب با مودال جزئیات، آزمایشگاه خلاقیت و هوش مصنوعی، تجربه تدریس، جعبه‌ابزار، تحصیلات و ارتباط مستقیم.
5. **محتوای کاملا مستند و واقعی**:
   - تفکیک کامل داده‌ها در `src/data/resumeData.ts` بدون دستکاری یا تولید اطلاعات ساختگی.

## راهنمای راه‌اندازی و اجرای محلی

### پیش‌نیازها
- Node.js (نسخه ۱۸ یا بالاتر)
- pnpm یا npm

### نصب وابستگی‌ها
```bash
pnpm install
# یا
npm install
```

### اجرای محیط توسعه (Development Server)
```bash
pnpm dev
# یا
npm run dev
```
سپس مرورگر خود را روی آدرس `http://localhost:3000` باز کنید.

### بیلد پروداکشن (Production Build)
```bash
pnpm build
# یا
npm run build
```
فایل‌های کامپایل‌شده در پوشه `dist` تولید می‌شوند.

### پیش‌نمایش بیلد (Preview)
```bash
pnpm preview
```

## استقرار روی Vercel (Vercel Deployment)

این پروژه به صورت استاتیک با Vite کامپایل می‌شود و آماده استقرار فوری روی پلتفرم Vercel است:
1. مخزن گیت را به گیت‌هاب پوش کنید.
2. پروژه را در داشبورد Vercel ایمپورت کنید.
3. فریم‌ورک پیش‌فرض `Vite` به صورت خودکار شناسایی می‌شود:
   - **Build Command**: `pnpm build` (یا `npm run build`)
   - **Output Directory**: `dist`
4. روی **Deploy** کلیک کنید تا وبسایت ظرف چند ثانیه منتشر شود.
